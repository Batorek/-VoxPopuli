Uruchomienie:
1. Utworzyć plik .env w katalogu głównym projektu.
2. Dodać (jest na mv w pliku .env):
   NEXT_PUBLIC_MAPBOX_TOKEN=...
   BIELIK_API_KEY=...
3. Uruchomić:
   docker compose up --build -d
4. Aplikacja:
   frontend: http://localhost:8904
   backend API: http://localhost:8902/api# -VoxPopuli
